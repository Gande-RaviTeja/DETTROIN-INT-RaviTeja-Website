##  Technologies Used

- **Frontend**: React 19, Vite, TypeScript
- **Styling**: Tailwind CSS v4, Vanilla CSS
- **Animations**: Framer Motion
- **Interactive Features**: HTML5 Canvas (`destination-out` scratch-off compositing)
- **Icons**: Lucide React, React Icons

---

##  Key Improvements Made

### 1. Modern UI/UX Redesign
- Custom visual aesthetic using Deep Navy (`#0B2341`) and Gold (`#D4AF37`) theme with `Cormorant Garamond` serif typography, glassmorphism cards, and shadow depth.

### 2. Interactive Scratch Reveal Canvas
- Built a 60 FPS HTML5 Canvas scratch-off card (`destination-out` compositing) featuring a glowing `" SCRATCH ME "` overlay and real-time reveal progress counter.

### 3. Dynamic Hero Slideshow
- Smooth cross-fade background slider cycling every 5 seconds through 5 authentic Vasant Valley photos with interactive manual slide selection pills.

### 4. Reordered Navigation
- Rearranged top navbar links in exact page layout order (`Home` --> `About Us` --> `Learning Experience` --> `Academics` --> `Life at VVS` --> `Infrastructure` --> `Admissions` --> `Contact`) with sticky offset smooth scrolling.

### 5. Dual-Role Auth Modal
- Role-specific login and registration portals for both **Student Portal** (Admission No. & Grade) and **Faculty Portal** (Staff Code & Teaching Dept).

### 6. Interactive Modals & Application Flows
- Multi-purpose popups for Admission Enquiries, a 35-Year Legacy Timeline (1990–2026), Student Achievements Trophy showcase, and Campus Lightbox.

### 7. Responsive & High Performance
- Fully responsive across Mobile, Tablet, and Desktop with zero build errors (`vite build` in ~7.9s) and smooth 60 FPS animation loops.
